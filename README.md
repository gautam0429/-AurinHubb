# Finora

A responsive finance dashboard web application built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

This project demonstrates a modern frontend architecture with reusable components, responsive layouts, interactive UI workflows, and production-oriented design practices.

---

## Features

- Responsive layout for Mobile, Tablet and Desktop
- Modern dashboard interface
- Interactive navigation
- Goal management UI
- Budget management UI
- Account overview
- Transaction history
- Search interface
- Notification center
- Currency selector
- Dark mode support
- Reusable component architecture
- Demo data for showcasing UI workflows

---

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

---

## Getting Started

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
